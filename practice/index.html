配信練習の手順

初配信の前に、本番と同じ画面で配信の操作を練習します。配信には映りません（15分ほど）。この3つが終われば練習はおしまいです。

  1. 配信の準備ができているか見る
    • カンペのAIが開いている
      Claude Code か Codex の画面に「準備できました。手順書を見て進めてください」と出ていればOK（出るまで1〜2分かかります）
    • 配信パネルが開いている
      Google Chrome に、この画面が出ていればOK
  2. 配信パネルで「🔰 自主練習」を押して、画面の案内に従って配信の操作を覚える
  3. 「✅ 練習はここまで」と出たら、カンペのAIに「終わった」と伝える
    AIが Addness のタスクを完了にします
